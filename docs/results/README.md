# Results and evidence

Every number here is **measured, dated and real**. Nothing is estimated or rounded up.

## Where evidence lives
| Public (this repo, redacted only) | Private (`evidence/` folder in my Google Drive) |
|---|---|
| Screenshots with names, emails and links blurred, or showing demo data | Unredacted screenshots |
| `counts.md`: the numbers and the date measured | Asana export CSV of the real board |
| `timing.md`: before and after times | Source notes for each backfilled request (screenshots of the original DM/email) |
| Example emails with personal details removed | Raw confirmation and Needs Info emails |
| | Before/after Drive folder-tree screenshots with real file names, CopyLog and UndoLog exports |

**Never in the repo:** member names, emails, form responses, Drive/Sheet/Form/Asana links, the Asana token, or photos of members.
