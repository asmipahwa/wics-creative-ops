# Weekly status update: before vs after

**Rule:** record what the stopwatch says. If "after" isn't ~15 minutes, write the real number. Don.t round it to a target.

## How to time it
**Before (the old way):** pick a real week. Start a stopwatch when you begin collecting status. That means checking DMs, group chats and emails, asking people "where's X at?", and writing the update for the exec team. Stop it when the update is sent. Pause it while you're waiting on replies, but note how long you waited.

**After (the new way):** in a real week, start the stopwatch when you open the Monday summary email or the Dashboard. Stop it when the update is sent to the exec team. That includes checking the numbers, adding context and forwarding.

Time a few weeks if you can. One week is a data point, not a trend.
